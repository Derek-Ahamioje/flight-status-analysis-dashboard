# Flight Status Analysis Dashboard

## Project Overview

This project uses Power BI to analyse airline operational performance by examining flight delays, cancellations, on-time performance, and air traffic trends.

Interactive dashboards were developed to enable stakeholders to monitor airline performance, identify operational bottlenecks, and support data-driven decision-making.

---

## Business Problem

Flight delays and cancellations can significantly impact operational efficiency, customer satisfaction, and airline performance.

The objective of this project was to develop an interactive Business Intelligence solution capable of monitoring flight performance and identifying patterns affecting operational reliability.

---

## Dashboard Features

- Flight status monitoring
- Delay analysis
- Cancellation analysis
- On-time performance reporting
- Airline performance comparison
- Air traffic analysis
- Interactive filtering by month and airline
- KPI performance tracking

---

## Key Insights

- Flight delays represented the largest operational issue within the dataset.
- Significant variation existed among airline operators.
- On-time performance varied across days of the week.
- Airlines demonstrated different delay patterns across multiple years.
- Interactive filtering enabled detailed airline-specific performance analysis.
